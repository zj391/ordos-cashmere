## 从可核验的声明起步

"羊绒"不是品质等级、不是手感描述，也不是纤维成分声明的替代品。对于开发自有品牌针织系列的买家来说，它应该被视为一个需要与产品规格、批次记录匹配——在商业风险需要时——独立检测结果匹配的声明。

这个区别在样品变成大货时最为关键。一块漂亮柔软的手织样片可以帮助确认颜色与手感，但**它本身无法确定成分、纤维直径分布，或后续大货批次是否与已批准标准一致**。把核验流程在采样前就嵌入采购规格，而不是在包装后试图重建。

对于出口美国的羊毛产品，美国联邦贸易委员会（FTC）规定**羊绒**仅指山羊的去粗毛细绒底纤维。其指引还描述了羊绒平均纤维直径19微米的限制、超过30微米纤维的比例上限，以及24%的均值变异系数上限。这些都是**标签法定定义要求**——并非通用奢华排名系统——买家不应把单一微米数字当作所有性能或价格决策的捷径。[1](https://www.ftc.gov/business-guidance/resources/cachet-cashmere-complying-wool-products-labeling-act)

> **买家原则**：将每个营销或标签声明匹配到可定义的指标——平均纤维直径、含粗毛率（>30μm 纤维比例）、纤维变异系数、重量百分比、染色牢度。

## 标准检测报告含什么、不含什么

一份合规的羊绒检测报告通常由第三方检测实验室（SGS、Intertek、CTI、Testex、CCIS 等）出具，按 ISO/ASTM 标准方法：

| 指标 | 标准 | 测量什么 |
|---|---|---|
| 平均纤维直径 | ISO 137 / IWTO-8 | 平均微米 + 标准差 |
| 含粗毛率 | IWTO-8 | >30μm 纤维占比 |
| 变异系数（CV%） | IWTO-8 | 直径分布的离散度 |
| 纤维长度分布 | ASTM D5103 | 加权平均长度 + 长度直方图 |
| 单纤维强度 | ASTM D3822 | 单根断裂强度（g/denier） |
| 纤维含量 | ISO 1833 / AATCC 20A | 羊绒/羊毛/其他比例 |
| 染色牢度 | ISO 105-C06 / AATCC 61 | 洗涤/光/摩擦色牢度 |
| 起球等级 | ISO 12945-2 / Martindale | 抗起球等级（1-5） |
| pH 值 | ISO 3071 / AATCC 81 | 织物酸碱度（皮肤安全） |

但**任何检测报告都不替代纤维手感**。报告能告诉你纤维是否符合规格，但无法告诉你**纤维是否符合你的产品定位**——这是买家的判断。

## 买家核对清单

按以下清单向供应商或第三方检测索取：

1. **平均纤维直径（μm）** + 标准差
2. **含粗毛率（% >30μm）** — 商用≤1.0%，顶级≤0.5%
3. **CV% 变异系数** — 商用≤24%，顶级≤22%
4. **纤维长度直方图** — 主峰在 36-42mm
5. **纤维强度** — ≥4.5 g/denier（决定成衣耐穿度）
6. **第三方检测日期** — 6 个月以内的报告更有参考价值
7. **检测方法** — 必须按 ISO 或 IWTO 标准
8. **实验室资质** — ISO 17025 认证或同等

## 红线：买家必须自己验证

有些供应商口头承诺"14.5μm 100% 羊绒"——但**单凭供应商的话不够**。买家应：

1. **首单必测**：首笔订单 100% 第三方检测
2. **大货抽样**：每 50kg 纱线或 500 件成衣抽 1 份
3. **跨批检测**：每个新批次都测，不要"延续上批次报告"
4. **实地抽检**：每 3-6 月派人或委托代理到工厂实地抽样

**常见陷阱**：
- 工厂给你"工厂内部检测报告"——这不是第三方，**不算数**
- "我们的羊绒 14.5μm"——但**没第三方报告支撑**——口头声明不能写入合同
- 检测报告**日期 6 个月以上**——纤维可能来自不同批次

## 标签与合规

不同市场有不同标签规则：
- **美国**：FTC 19μm 限制、24% CV 上限、纤维含量声明
- **欧盟**：100% 羊绒 = 平均直径 ≤19μm + 含粗毛≤3% + 变异系数≤24%（EU 标准）
- **中国**：FZ/T 73001-2004 标准——与 EU 类似
- **日本**：JIS L 1902-1998——平均直径 ≤19μm，含粗率≤3%

**出口订单必须**：
- 标签按目标市场要求
- 提供对应语言的成分声明
- 检测报告含**ISO 17025 实验室盖章**

## 工厂实地审查

好的工厂提供：
- 第三方检测报告**随每批订单提供**——不是首单才做
- 检测报告**批次号与生产批号匹配**——可追溯
- **年度复审报告**——长期合作关系下的第三方年度质量审查

不好的工厂：
- 拒绝第三方检测
- 检测报告日期过期
- 检测报告**只显示平均值**，不显示分布
- 检测报告**无法与具体批次对应**

## 不可测的"质量"

检测报告测的是纤维本身的物理特性。但**以下"质量"无法检测**：
- **手感**（柔软度、滑度）—— 经验判断
- **纤维来源**（内蒙古 / 蒙古 / 阿富汗 / 西藏）—— 实地经验
- **抓梳时间**（春梳 / 秋梳）—— 实地经验
- **染色工艺**（色光、色牢度、染料环保）—— 部分可测，部分靠经验
- **整理工艺**（丝光、防缩、防起球）—— 部分可测

这些"软质量"靠**实地经验 + 长期供应商关系**。第三方检测报告是基础门槛，不是终极答案。

## 完整核验流程

新供应商首次合作的核验流程：

1. **索取检测报告**（第三方 + ISO 17025）
2. **评估报告**——按上述清单核对
3. **实地访厂**（或委托第三方代理）——看生产线、分级车间、库存管理
4. **试片**——确认手感、颜色、款式
5. **首单 + 第三方首单检测**——再生产大货前再测一次
6. **大货 + 第三方抽检**——出货前 1 周
7. **年度复审**——长期合作每年再测一次

**全流程周期 8-12 周**，但**省略任何环节都增加风险**。

## 与工厂沟通的实用话术

向工厂询问时使用以下话术（避免供应商糊弄）：
- "请提供近 3 个月的 ISO 17025 检测报告"
- "请提供这批订单的具体批次号及对应检测报告"
- "请提供纤维含粗率的分布直方图"
- "请提供您的分级车间视频或照片"
- "请提供首单 / 大货 / 出货前 3 个时间点的第三方检测流程"

如果工厂**回避任何一项**——这是红旗（red flag）。
