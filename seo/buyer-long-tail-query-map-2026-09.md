# ordos-cashmere Buyer Long-Tail Query Map (2026-09)

Framework document. No real search-console data available — these are
buyer-intent queries reverse-derived from existing blog topics, category
structure, tag pages, and product facets. Marked "framework" because
search volume is not verified; treat as candidate list for landing-page
or content targeting, not as keyword-volume claims.

Each query is graded:
- **A** = direct commercial intent, buyer in active procurement
- **B** = research intent, buyer comparing options
- **C** = informational, awareness-stage

Confidence that buyer is in B2B procurement stage (vs retail browsing):
- **HIGH** = explicit B2B terms (wholesale, MOQ, manufacturer, supplier, factory, FOB, OEM, OD)
- **MED** = implicit B2B context (grammage, micron, certification names)
- **LOW** = generic terms that could be retail

## 5. Internal-link priority (this is where to invest first)

If only 5 internal-link improvements are made in 2026 Q4, prioritize:

1. **Blog → product category page**: every existing indexable blog post
   should link to the relevant product category (not just to other blogs).
   Currently the internal-link network is blog-heavy; product pages are
   under-linked from blog context.

2. **Product category → blog**: the 5 category hubs (garment-oem,
   accessories-cat, scarves, hats-accessories, yarn) should feature
   "Recent sourcing notes from our factory" sections linking to the
   3 newest blog posts.

3. **Tag page → blog**: each of the existing tag pages should link to
   the 1-2 blog posts that are most relevant to that tag's buyer intent.

## 6. Limitations and what this is not

- **No real search-console data.** None of these queries are ranked by
  observed search volume. They are reverse-derived from existing content
  structure.
- **No keyword-tool estimates.** Google Keyword Planner, Ahrefs,
  Semrush, etc. are not in use here. If you have access to those
  tools, this list should be cross-checked before content is committed.
- **No competitor overlap analysis.** We have not compared these
  queries against what Loro Piana, Falconeri, Gobi, etc. are actively
  bidding on. If you have competitor SERP data, that's the highest-ROI
  input for refining this list.
