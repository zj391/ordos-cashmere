# 分类枢纽与产品详情页结构审阅（2026-08-27）

本轮以英文纱线分类页和 `yarn-106` 产品详情页为代表进行本地预览审阅。分类页首屏的排版具有品牌气质，但右侧大面积留白未承担产品浏览任务；长标题占据主要视觉重心，首屏未把真实的产品记录、包装形式和规格比较路径作为直接可见的决策线索。

产品详情页首屏具备左图右文的基础，但超长标题、书面确认提示、标签与产品亮点依次堆叠，用户需要继续下滑才能形成完整规格判断。规格信息本身来自目录且应继续保留，但需要形成更清晰的“规格摘要—技术明细—询盘行动”三段关系。

本轮选择“暖灰采购档案”方向：分类首屏采用非对称的主标题与右侧规格导航栏，产品页采用更强的规格账本式摘要卡与并列行动区。改版应使用已有图片和真实目录属性，不新增未经核验的认证、价格、库存、MOQ、交期、样品、物流、付款、产能或服务范围承诺。

第二次本地预览显示，分类枢纽首屏已将产品记录数量、检索主题和目录锚点并入深色规格索引侧栏，原本闲置的右侧空间已成为可操作的浏览入口。产品页已形成左侧图像档案与右侧产品记录卡的双栏关系，标题、书面确认提示和规格账本在同一阅读路径内呈现；主图仍使用现有目录图片，未替换产品资产。

手机视口审阅确认，分类首屏和产品首屏均已按单列回流，主图及标题未出现横向截断。不过，现有三枚悬浮联络按钮位于阅读列右侧中段，会遮挡分类页项目符号与产品页标题区域；该交互组件需要改为更靠近屏幕底部的紧凑停靠方式，以免影响窄屏阅读。
