## 暂定最高优先级

产品详情页的旧版生产能力与商业条件模块影响所有产品 URL，且会削弱当前“规格账本 + 项目书面确认”的信息边界，因此应优先收敛。改动应保留主图、产品记录、真实规格、技术字段、相关产品、质量准备、询盘与加入询价单能力；将无法由当前目录支持的生产、价格、库存、交期、最低量、检测和产能叙述替换为基于产品参考、规格、数量、目的地、验货和文件需求的项目准备路径。产品总目录的比较流程可作为下一轮体验优化。

## 已实施的最高优先级收敛

产品详情模板现停用可能携带旧版生产、检测、库存、交期、最低量、价格、产能、固定附加费用或服务范围断言的详情模块，包括技术规格扩展、材料故事、工序、定制服务、选择理由、应用场景、OEM 工作流、护理与定制选项。首屏图像档案、产品标题、规格账本、仅由目录直接列出的材料/细度/颜色/尺寸/包装/重量、相关产品、质量核验准备、加入询价单与询盘表单均保留。

产品摘要改为对白名单式织法字段进行提取，仅可输出精纺、粗纺、提花、麻花针织、平针织、针织或针距等中性构造术语；设备、国家、厂商、检测机构、工厂、定制与商业承诺等词不会进入摘要。六语元描述与元关键词同步只使用清洁产品名、目录材料、分类与已列规格，并以“项目条件书面确认”界定采购沟通边界。用于询价单客户端交接的既有价格、货币和最低量数据未被删除，但不再作为可见内容或 Product Schema 事实输出。

页脚的六语定位与版权行同步改为“产品记录与 B2B 采购信息/书面确认”语义，移除“源头工厂”“无中间商”与成立年份暗示，同时保留产品、资源和联系路径。

## 后续目录决策路径观察

英文总目录首屏现有分类档案索引、分类筛选、关键词搜索、排序、材质筛选、逐卡“Compare”按钮、产品详情卡片和询盘入口。它们均可见且不依赖额外路由，但在筛选区下方，比较与查看详情以并列动作出现，采购方尚未获得明确的下一步提示：应先缩小结果、选取少量产品比较，还是直接打开规格账本。因此，下一轮应在不改变原有筛选、比较、分页或询盘逻辑的前提下，强化“筛选 → 选取至多三款 → 比较/加入询价单”与“直接查看单款详情”的分流说明及状态反馈。

比较功能实测表明，卡片点击后会将按钮改为已选状态，并在底部显示“已选 1 款／最多选择 3 款”、清除和“比较已选”操作。因此现有能力可用，问题集中于首次选择前的可发现性：用户未必知道比较上限、比较字段和“直接进入产品档案”之间的差异。下一步改动应以前置、简短的目录步骤说明和更明确的卡片动作命名来解决，而非重写比较逻辑。

更新后的桌面复测显示，三步说明置于目录控制台之前，明确区分“缩小目录”“查看单款档案”和“比较候选款”；产品卡片的主动作已由可能造成误解的询盘文案改为“查看产品记录”。页面重新加载及触发客户端筛选重绘后，动态卡片亦保留该产品记录入口，原有单独的 Compare 操作、底部比较栏和询盘主入口仍在。

在静态复核中，还发现中文与韩文目录页面的客户端标签 JSON 序列化了未在目录页面使用的旧翻译副标题，其中含工厂直供、价格、OEM/ODM 与可追溯性断言。该字段不是筛选、比较或卡片渲染的依赖，现已只从目录页面的序列化对象中移除；原始翻译资源、产品记录和现有客户端功能均未删除。目录页面本身的六语标题与关键词也已改为产品目录、产品记录和具体产品类别语义，不再使用工厂直供或 OEM 断言。

## 分类枢纽大规模升级审阅（进行中）

以英文帽子分类枢纽为共享模板代表的桌面审阅表明，当前分类首屏的规格索引、产品记录数量、搜索主题和“浏览记录”入口已经可用，产品网格也保留了图像与真实产品详情链接。但每张卡片目前只呈现产品名称和通用的“项目条件书面确认”提示，采购方不能在列表层快速区分已列材料、细度、尺寸、包装、重量或中性构造属性；必须逐个打开详情页才能建立候选清单。

当前页面还将“产品记录浏览”“邻近分类跳转”“采购准备”“相关指南”和“询盘行动”依序分散在多个独立区块。下一轮共享模板重构应将其组织为一条可扫描的采购路径：分类档案与真实规格地图 → 具备关键已列规格的产品记录 → 项目准备与质量路径 → 询盘行动。改动只从产品目录提取可直接支撑的字段，不将价格、最低量、交期、库存、设备、认证、服务范围或厂商身份作为可索引事实。

共享模板已开始重构。帽子与纱线分类的桌面实测显示：首屏后新增“已列属性地图”和“候选款路径”，产品卡片新增产品参考、材料、细度以及在目录中已列的包装或重量信息，并保留每张卡片原有的详情链接。首轮样式实测发现全局偶数区块背景规则会覆盖深色属性地图，已用局部规则修复；纱线目录中还存在“Color Cards”“多种颜色可选”等通用颜色占位词，现仅在新属性地图中排除这些非具体颜色标签，原始产品记录未被删除或改写。

英文与中文纱线分类复测确认：六语共享的属性地图、三段候选路径、详情链接、质量准备和询盘入口均能呈现；分类属性地图仅保留可识别的目录颜色。部分产品的包装字段为“See specification”一类通用跳转提示而非具体包装规格，现从新卡片摘要中排除，以免将其误读为产品事实；具体包装仍可在产品详情页的规格账本中保留和核对。
