# 核心路径体验审阅记录（2026-08-28）

## 审阅范围

已在本地桌面预览中审阅英文首页（`/en/`）、产品总目录（`/en/products/`）、代表产品详情页与博客归档；随后对全量六语产品静态页执行内容与抓取信号回归检查。审阅目标是识别会阻碍采购方理解产品范围、找到具体规格或开始书面询盘的界面问题；本记录不对企业能力、交期、价格、库存或服务范围作事实判断。

## 已确认发现

| 路径 | 已观察到的优势 | 候选问题 | 优先级 |
|---|---|---|---|
| 首页 | 首屏具备明确的产品资料定位、主询盘与目录下载动作，五个分类入口可见。 | 分类入口与主导航使用相同的产品家族信息，但进入具体规格的下一步提示仍分散在首屏、产品范围和精选记录之间。 | 中 |
| 产品总目录 | 分类索引、总量、筛选、产品卡片、比较与分类页入口均可用，并在首屏连续出现。 | 同屏同时出现“目录索引”“分类标签”“材质筛选”“比较按钮”与悬浮联系栏；采购方在选中具体产品前不容易知道应先使用“比较”还是进入详情页。 | 高 |
| 产品详情页 | 主图、产品标题、规格账本、详情页链接和询盘入口已形成较明确的档案式阅读顺序。 | 主规格账本之后仍出现旧版生产设备、检测、库存、交期、最低量、固定附加费用、产能和“无中间商”等叙述；它们与产品记录的真实规格区并列，易造成采购方无法分辨可直接查阅的信息与需书面确认的项目条件。 | 最高 |
| 博客归档 | 已恢复所有保留文章的可访问性；首屏明确说明文章可见性与搜索索引白名单的区别，近期审阅文章置于最前。 | 历史文章的标题与摘要可能保留旧时行业表述，但归档与历史文章既有 noindex 边界；这不是当前最优先的页面结构阻塞点。 | 低 |

## 暂定最高优先级

产品详情页的旧版生产能力与商业条件模块影响所有产品 URL，且会削弱当前“规格账本 + 项目书面确认”的信息边界，因此应优先收敛。改动应保留主图、产品记录、真实规格、技术字段、相关产品、质量准备、询盘与加入询价单能力；将无法由当前目录支持的生产、价格、库存、交期、最低量、检测和产能叙述替换为基于产品参考、规格、数量、目的地、验货和文件需求的项目准备路径。产品总目录的比较流程可作为下一轮体验优化。

## 已实施的最高优先级收敛

产品详情模板现停用可能携带旧版生产、检测、库存、交期、最低量、价格、产能、固定附加费用或服务范围断言的详情模块，包括技术规格扩展、材料故事、工序、定制服务、选择理由、应用场景、OEM 工作流、护理与定制选项。首屏图像档案、产品标题、规格账本、仅由目录直接列出的材料/细度/颜色/尺寸/包装/重量、相关产品、质量核验准备、加入询价单与询盘表单均保留。

产品摘要改为对白名单式织法字段进行提取，仅可输出精纺、粗纺、提花、麻花针织、平针织、针织或针距等中性构造术语；设备、国家、厂商、检测机构、工厂、定制与商业承诺等词不会进入摘要。六语元描述与元关键词同步只使用清洁产品名、目录材料、分类与已列规格，并以“项目条件书面确认”界定采购沟通边界。用于询价单客户端交接的既有价格、货币和最低量数据未被删除，但不再作为可见内容或 Product Schema 事实输出。

页脚的六语定位与版权行同步改为“产品记录与 B2B 采购信息/书面确认”语义，移除“源头工厂”“无中间商”与成立年份暗示，同时保留产品、资源和联系路径。

## 静态验证结果（2026-08-28）

完整生产构建和 sitemap 生成通过。构建后，对 3,540 个多语言产品静态页扫描 `Italian Sant'Agostino`、`French NCSI`、`German STOLL`、`OFDA`、库存、产能、无中间商、定制纱支、Pantone、固定附加费、固定交期、固定 MOQ、成立年份及旧工厂元关键词等残余断言，命中页数为 **0**；`Offer`、`priceCurrency` 与 `InStock` 的产品页命中页数亦为 **0**。

同一纱线产品的英文、中文、德文、法文、日文与韩文静态页均保留一个 H1、尾斜杠 canonical、hreflang、一个 Product Schema、加入询价单动作、询盘表单和本地化质量控制路径（`/[locale]/quality-control/`），且未设为 noindex。六语代表产品页的页脚旧断言命中为 0。生成的 sitemap 统计为 static=108、blog=5、products=3522；根级 API 入口保持为 5。构建产生的临时 `dist` 已在验证后清理。构建日志中既有的 Tailwind 歧义、动态路由冲突和 admin 预渲染警告仍存在，但本轮构建正常完成，未将其视为本轮失败。
