# 产品标题长尾语义覆盖增强审计

## 审计发现

上一轮标题规则只使用原始名称、材质与细度。目录中还存在适合谨慎补充的直接字段：织法 158 条、图案 158 条、季节 180 条、人群 150 条、尺寸 183 条、领型/版型 126 条。所有产品都有标签，但其中包含 OEM/ODM、畅销等不应作为事实型标题的营销词，因此不直接用于标题。

## 属性规则

扩充器继续以产品原始名称为第一层差异，再依次考虑未在名称中出现的材质、细度、图案、领型、织法、人群、季节与尺寸。规则会排除空值、占位符、超过 48 个字符的异常字段、`custom`、OEM/ODM、Bestseller、地区范围及设备/供应来源断言。尺寸仅接受明确的尺码组或物理尺寸；季节与人群使用六语本地化词。

这使标题覆盖更多可检索的真实属性，同时避免在标题中加入价格、MOQ、库存、样品、交期、认证、产能、服务地区或未经核验的性能承诺。

## 静态验证

完整构建成功。每种语言的 582 个真实产品详情页均有标题和 H1；实际产品标题与 H1 的重复数均为零，canonical 数量正确。每种语言中，582 个真实产品详情 H1 都包含至少一个扩充属性，518 个包含两个或以上属性。`<title>` 最大长度为 112 个字符；六语平均长度分别为英文 104.9、德文 104.6、法文 105.4、日文 100.1、韩文 100.0、中文 92.1 个字符。产品 sitemap 仍为 3,522 个 URL，根级 API 入口仍为五个。

Google 的建议是标题应描述性、简洁、与页面主体一致，并避免关键词堆砌；搜索结果标题会综合 `<title>`、H1 和其他页面信号。[1](https://developers.google.com/search/docs/appearance/title-link) 因此扩充后产品名称、H1、`Product.name` 和面包屑末项共享同一真实字段来源。

## 持续维护

若业务方希望继续增加标题覆盖，应优先补充经核验的产品字段，例如本地化款式名称、明确的尺寸、图案、版型、织法、适用人群与季节。不要将交易条款、认证、性能、成本或可用性字段写入标题，除非每个产品的适用范围与有效性可独立证实。
