# 服务 Schema 与私牌 OEM 页面 SEO 审计

## 修复范围

服务型 Schema 原先按语言输出固定的服务国家范围、产品数值规格和 OEM 最低起订量。私牌页面也包含固定样品、量产、物流、售后、费用、库存、回款和报价时效承诺。这些值不一定适用于每种产品、目的地或项目条件，且部分未在当前工作中获得独立核验。

本轮将服务 Schema 改为采购沟通型描述，不再标注服务国家范围、固定产品规格或固定 MOQ。私牌页面改为六语采购准备内容：买方提供产品参考、规格、数量、目的地、打样和文件要求；MOQ、样品、价格、交期、包装、交付条款和验收事项均按具体项目在书面报价或销售协议中确认。

## 结构化数据原则

Google 的通用结构化数据指南要求标记真实代表页面可见内容，避免使用无关、隐藏或误导信息。[1]

对于 Organization 和服务相关标记，Google 建议仅添加真正适用于页面和组织、且对用户有用的属性。[2]
